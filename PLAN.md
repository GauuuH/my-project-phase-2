# DECIDER Phase 2 - Plan V1

## Day 1
Finalize the basic game rules and the five player roles. Decide what Environment, Movements, Actions, Objects, and Tools can control.

## Day 2-3
Build the basic website prototype. Create the digital character, player role pages, and simple actions. Test one or two physical interactions such as Blow and Shake.

Add the basic shared-room system so multiple phones can send their choices to the same game and create a combined result.

## Day 5 / Playtest
Test the prototype with multiple players. Focus on whether different roles and hidden choices can create an understandable and interesting shared result.

For the first playtest, I will focus on the basic multiplayer relationship instead of trying to finish the whole game. More visual effects, interactions, and game rules can be developed after the first test.

I don't have an exact date for every task because I also have assignments from other courses. I will arrange these development days based on my available time. For example, I plan to finish the Day 1 tasks on Friday afternoon and work on the Day 2-3 tasks during the weekend.
